# جعبه‌ابزار الکترونیک | Electronics Toolkit

**فارسی:** ابزار تک‌فایلی و آفلاین‌پذیر برای دانشجویان و علاقه‌مندان الکترونیک: ماشین‌حساب‌ها، شبیه‌ساز DC (MNA) و پاسخ پله RC، دستیار Gemini و لینک ابزارهای بیرونی.
**English:** A single-file, offline-capable toolkit: calculators, DC (MNA) simulator, RC transient, Gemini assistant and external tool links.

## Features
- Ohm, divider, LED resistor (E24), RC filter, 555, dB, number systems, resistor colour code
- Netlist DC solver (R, V, I) + RC step-response chart
- Gemini chat (your own API key, stored locally)
- Links: Falstad, Tinkercad, Wokwi, EasyEDA, KiCad, LTspice, WEBENCH + part search (Octopart, AllDatasheet, Digi-Key, Mouser)
- Dark/light theme, FA/EN, shortcuts (1–4, Ctrl+K, Esc), PWA

## Deploy
1. Push all files to a GitHub repo (branch `main`).
2. Settings → Pages → Source: **GitHub Actions**.
3. The workflow in `.github/workflows/deploy.yml` publishes on every push.
